# @devpilot/web (planned)

React web UI for DevPilot AI.

Planned responsibilities:

- Submit a failure signal and watch the investigation live from the event stream.
- Show competing hypotheses with their supporting and contradicting evidence.
- Render reports where every claim links to the evidence it cites.
- Show the red-to-green verification result and the proposed diff.
- Talk only to `@devpilot/api`; contain no investigation logic of its own.
